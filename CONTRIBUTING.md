# Contributing to Agent Skill Forge

We love your input! We want to make contributing to this project as easy and transparent as possible.

## How to Contribute

1.  **Add New Skills**: Found an awesome agent skill?
    *   Fork the repo.
    *   Add the link to `raw_data_sources.txt` (if we add one) or just open an Issue suggesting it.
    *   Currently, we crawl the curated list. If you want your skill included, ensure it's high quality!

2.  **Improve the Engine (`skill_forge.py`)**:
    *   Have a better prompt strategy?
    *   Can you improve the stack detection logic?
    *   Submit a PR!

3.  **Report Bugs**:
    *   If the script crashes on your repo, please file an issue with your OS and Python version.

## Development Workflow

1.  Clone the repo.
2.  Install requirements (standard library only for now!).
3.  Run `python skill_forge.py` on test directories.
4.  Submit a Pull Request.
