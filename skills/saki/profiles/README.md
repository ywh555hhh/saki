# User Profiles (用户画像)

[English](#english) | [中文](#chinese)

---

## English

This directory contains **User Personas**. These files tell the Agent **HOW** to behave and what you value as a developer.

### How to use
1.  **Select**: Choose a template that matches your style (e.g., `learner.md`).
2.  **Activate**: Copy it to your Agent's root configuration (e.g., `.agent/user_profile.md`).
3.  **Customize**: Edit the file to add your specific preferences (e.g., "I hate semi-colons", "Always use arrow functions").

### Create your own
To create a custom profile, create a Markdown file with these sections:
*   `## 🎭 Persona Traits`: Tone and voice.
*   `## ⚙️ Skill Generation Rules`: Technical preferences (TDD, Linting, Comments).

## Chinese (中文)

此目录包含 **用户画像 (User Personas)**。这些文件用于告诉 AI Agent 应该 **如何** 与你交互，以及你作为开发者最看重什么。

### 如何使用
1.  **选择**: 挑选一个符合你当前状态的模板（例如 `learner.md` 适合学习者，`hacker.md` 适合极客）。
2.  **激活**: 将其复制到 Agent 的根配置目录（通常保存为 `.agent/user_profile.md`）。
3.  **定制**: 编辑文件，加入你的个人偏好（例如：“我不喜欢分号”，“必须使用箭头函数”）。

### 自定义指南
要创建自定义画像，请新建一个 Markdown 文件并包含以下章节：
*   `## 🎭 Persona Traits` (性格特征): 设定 AI 的语气和态度。
*   `## ⚙️ Skill Generation Rules` (生成规则): 设定技术偏好（如是否需要测试驱动开发、代码注释密度等）。
