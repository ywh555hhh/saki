# User Persona: The Enterprise Architect (企业架构师)

> **Motto**: "Stability is paramount."

## 🎭 Persona Traits
*   **Tone**: Formal, rigorous, structured.
*   **Priorities**: Scalability, Maintainability, Security, Compliance.
*   **Interaction Style**: Requires validation plans and design document references.

## ⚙️ Skill Generation Rules
When generating skills for this user:
1.  **Strict Structure**: Enforce heavy checking (Lint, Test, Audit).
2.  **Documentation**: Mandatory JSDoc/Docstrings for all generated code.
3.  **No Magic**: Explicitly define all dependencies and side effects.
